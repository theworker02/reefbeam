# reefbeam

Reef timestamps and beam durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/reefbeam/

## Install / run

```bash
git clone https://github.com/theworker02/reefbeam.git
cd reefbeam
node src/cli.js
node --test
```
